# 已废弃：旧关卡、教程与 UI 流程详规

> 本文件属于旧设计树。有效模式详规：[`../.trae/knowledge/Design/GameModesAndProgression.md`](../.trae/knowledge/Design/GameModesAndProgression.md)。

## 空间结构

一期使用一张小型封闭校场或逻辑上连续的少量场景。准备区是安全区；训练区包含抓取、近战、盾牌、长矛、弓箭和瞬移训练点；战斗区中央开阔、边缘少量障碍；结果通过世界空间 UI 或安全结果区呈现。

## 准备区

提供重新校准、舒适度设置、主手设置、武器预览、进入训练和开始比赛。AI 不得进入或攻击准备区。武器架位置支持左右手自然抓取，并避免玩家靠近现实边界时必须弯腰或伸手过远。

## 教程结构

教程按能力解锁而非长文本说明：抓取/放下 → 单手剑有效命中 → 盾牌格挡 → 双手剑 → 长矛刺击 → 取箭/搭箭/拉弦/射击 → 瞬移 → 格挡后反击。每步包含触发条件、成功判定、失败提示、重试和跳过策略。

公开试玩默认要求首次玩家完成核心步骤；是否允许跳过全部教程属于假设。重复玩家可在准备区选择简化训练，但必须能再次进入单项训练。

## 比赛状态

比赛进入时锁定配置、生成或复位 AI、清空统计并显示短倒计时。战斗中 UI 只显示必要信息，避免固定在视野中心；生命、体力和瞬移冷却优先使用腕部、武器或场景化提示。胜负后锁定新伤害，延迟到安全结果状态。

## 结果与统计

显示胜负、持续时间、造成/受到伤害、命中、格挡、弓箭命中、瞬移次数和 AI 主武器。操作包括再战、换武器、返回训练和主菜单。结果操作需要防误触，并在选择后给出即时确认反馈。

## 引导原则

- 先演示动作，再要求玩家执行。
- 提示靠近相关物体，避免长时间贴脸文本。
- 同一失败不连续播放高强度声音。
- 成功反馈在动作完成后立即出现。
- 所有步骤都能在跟踪丢失、武器掉落和对象越界后恢复。

## 关卡约束

战斗区保持清晰边界和可预测地面，减少高低差、狭窄通道与复杂动态障碍。障碍数量和布局属于假设，只有在 M03 基础 AI 和瞬移稳定后才增加战术遮挡。

## 验收

- 新玩家无需口头说明可完成校准、核心训练和一局战斗。
- 每个教程步骤有成功、失败、恢复和重复入口。
- 结果菜单全部操作可达，且重开不残留上一局对象或统计。
- UI 不遮挡主要战斗视野，左右手和主手设置均可使用。
