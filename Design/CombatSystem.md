# 已废弃：旧战斗系统详规

> 本文件属于旧设计树。有效详规：[`../.trae/knowledge/Design/CombatSystem.md`](../.trae/knowledge/Design/CombatSystem.md)。

## 目标与边界

战斗系统把玩家的真实手部运动转换为稳定、可解释的游戏结果。规则覆盖近战轨迹、攻击有效性、格挡、伤害、硬直、死亡和武器解卡；抓取细节见 [武器系统](WeaponSystem.md)，AI 选择见 [AI 系统](AISystem.md)。

## 规则对象

- `AttackContext`：攻击者、武器、手、起止时间、轨迹样本、线速度、角速度和攻击标签。
- `ContactContext`：命中组件、接触点、法线、武器部位、目标部位和相对速度。
- `DefenseContext`：防守器具、朝向、覆盖区域、格挡开始时间和体力状态。
- `CombatResult`：无效接触、有效命中、普通格挡、完美格挡、盾牌承受、破防、致死。

这些名称是架构建议，具体 UE 类型和字段仍需实现评审，但语义已确认。

## 攻击状态机

`Idle → Armed → SwingCandidate → ActiveAttack → Recovery → Armed`。武器被稳定抓取后进入 Armed；运动超过起始阈值且方向连续时进入候选；满足武器允许的挥砍或刺击条件后激活；速度下降、方向反转、接触完成或超时后进入恢复。

同一 `AttackId` 对同一目标只结算一次主要伤害。重新命中需要先结束当前攻击，并满足最小分离、恢复和新方向条件，防止在碰撞体内抖动产生多次伤害。

## 连续轨迹检测

每个有效伤害部位保存上一帧和当前帧变换，使用 Sweep 或分段轨迹检测覆盖快速运动路径。刃、尖、柄使用不同命中标签；剑刃和矛尖可以造成主要伤害，柄部默认只触发轻碰撞或推挡。

攻击判定综合速度、角速度、轨迹长度、入射方向、武器部位和攻击状态。假设初始线速度阈值为 1.2—2.0 米/秒，刺击还需满足武器轴向与运动方向夹角；阈值必须在 M02 真机测试中按武器分别校准。

## 防守判定

普通格挡要求防守器具先于伤害部位接触攻击轨迹，并且接触点位于有效覆盖范围。完美格挡在普通格挡基础上检查防守启动时间、相对方向和剩余体力；初始时间窗 120—250 毫秒是假设。

| 结果 | 规则后果 |
|---|---|
| 无效接触 | 不扣血，轻声音/震动，不进入明显硬直 |
| 有效命中 | 计算伤害、受击方向、硬直和反馈 |
| 普通格挡 | 大幅减伤或免伤，双方轻反弹，消耗防守资源 |
| 完美格挡 | 防守者获得反击窗口，攻击者短暂失衡 |
| 盾牌承受 | 盾牌吸收攻击并消耗体力，低体力可能破防 |
| 破防 | 防守姿态被打开，进入短恢复窗口 |

## 伤害模型

伤害由武器基础值、有效速度映射、命中部位、攻击类型、防具系数和防守结果构成。速度不直接无限放大伤害，应使用有上限的曲线避免玩家用手腕抖动制造异常高伤害。头、躯干、四肢的倍率和护甲值属于假设，M02 先使用躯干统一生命模型，M04 再决定是否启用部位倍率。

## 硬直与动作承诺

玩家反馈以震动、音效、视觉和短时武器阻力为主，不强制移动头显或玩家身体。AI 可播放受击、失衡和死亡动画，但受击期间仍由规则状态禁止攻击取消。所有硬直时长需可配置，并避免连锁控制到无法恢复。

## 武器解卡

1. 接触时施加软阻力并允许沿表面滑动。
2. 持续监测低武器速度、连续接触时长和控制器位移差。
3. 认定卡住后降低约束或碰撞阻力，并沿接触法线/切线释放。
4. 释放后设置短暂再碰撞保护，避免立即重新锁住。

卡住判定时长、手柄与武器偏差和释放持续时间均是假设。M02 要记录每次自动解卡事件、接触对象和持续时间，用数据而非主观感觉调节。

## 反馈契约

每类结果拥有独立的音色、震动包络和视觉强度。有效命中、普通格挡、完美格挡和无效接触不得共享完全相同的反馈。血液表现遵守目标平台性能和内容分级，不能遮挡玩家主要视野。

## 验收

- 快速挥砍不会稳定穿过目标。
- 一次攻击不会重复扣除同一目标生命。
- 低速擦碰不会被误判为重击。
- 武器与盾牌接触后可滑动或在短时间内自动释放。
- 玩家与 AI 的同类攻击结果使用相同伤害语义。
- 连续重开后攻击 ID、命中缓存和硬直状态全部清空。
