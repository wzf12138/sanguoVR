# M00-T006 自动化、诊断与交付门禁

- 状态：见 `../active/STATUS.json`（本详规不复制动态状态）
- 优先级：P1
- 目标：建立最小自动化测试、日志、性能采样、构建验证和交付证据链。

## 交付

- 配置/数据资产有效性测试。
- 角色能力请求与状态转换单元测试。
- 武器命中去重、格挡和重置自动化测试入口。
- VR 输入/追踪调试面板。
- 1v1 基线与 4v4 压力采样地图规划。
- Win64 Editor 与 Android Development 构建门禁。

## 验收

1. 自动化失败可定位到任务和日志分类。
2. 关键系统都有重置和诊断入口。
3. 性能报告记录设备、构建类型、场景、采样时长和指标。
4. 未通过 Android/PICO 的变更不得标记设备已验证。
