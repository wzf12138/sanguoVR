## 3. 目标与非目标

**目标**
1. 让"核对"从**手写脚本**变成**声明式判据 + 固定执行器**。
2. 让 17 例同族失效**在机制上不可能发生**（不是靠人记得）。
3. 让新决策模型**无需读完全部 17 例**即可正确核对 —— **规则由工具承载，不由记忆承载**。

1. **不替代人做判断**：工具只回答"这条判据成不成立 / 过没过 / 有没有取到数"，**不回答"内容该不该这样写"**。

3. **不新建第二个 Skill**（`policy.md` §3 明令禁止平行 Skill）。
4. **不引入新依赖**：只允许 Python 标准库 + `pyyaml`（本机已验证可用）。

## 4. 工具规格（正式）

### 4.1 形态与位置
- **位置**：`.trae/tools/verify-claims.py`（项目工具；索引同步 `.trae/tools/README.md`）。
- **宿主语言**：**Python 3**（与既有 `check-integrity.py` 一致）。
  **理由（实测）**：PowerShell 格式串与 `-f` 的优先级冲突**反复**出现（`{m,n}`、`{0}` 两轮均致文本不渲染或数值错位）⇒ **不得把判据结论建立在 PowerShell 格式化输出上**。
- **调用**：绝对路径解释器（本机 Python 不在 PATH，命令见 `governance/SessionCommands.md` §校验）。
- **输出**：**文本 + 机器可读 JSON**（`--json <path>`），两者结论必须一致。

### 4.2 三态输出（**硬要求，最高优先级**）
每条判据的输出**必须**是三态之一，且**可区分**：

| 态 | 含义 | 何时产生 |
|---|---|---|
| **通过** | 判据成立且满足 | 测量值 == 期望值 |
| **未通过** | 判据成立但未满足 | 测量值 ≠ 期望值 |
| **未取到数** | **无法判定** | 文件不存在、命令无输出、读数为空、外部服务未索引 |

**⇒ 「未取到数」不得塌缩进任何一态。** 只有两态、且"未取到数"会塌缩的判据 = **缺陷判据**（三态判据原则）。
**⇒ fail-closed（默认）**：存在「未取到数」时**默认不判通过**（退出码非 0）；调用方须**显式**加 `--allow-unknown` 才可放行，且报告中必须保留该态的计数。

| 20 | **写入文书的哈希 / 指纹 / 计数必须自带格式自断言**：**① 逐字符复制自取数输出** —— **禁止手打、禁止补全、禁止沿用旧读数**；**② 带格式自断言（可执行三断言）**：**长度断言**（SHA256 = 64、`sha16` = 16）+ **字符集断言**（`^[0-9A-F]{64}$`，大写）+ **不得跨文书沿用**（须注明取数时点）；计数类 = 非负整数 + 分组和 == 总数 + 分母为实测；**③ 文书内部的分组计数之和必须 = 总数**（**禁止出现"标 6 项、实列 5 项"**）。**⇒ 书写形态：SHA256 一律以「双形态并写」** —— **分组形态**（8 组 × 8 位、组间空格）用于**人读与长度自校验**；**连续形态**（无空格 64 位）用于**机读、grep 与复制进命令**。**⇒ 只写分组形态则无法直接复制执行；只写连续形态则无法肉眼校验长度；两者并写才同时具备「可读校验」与「可机执行」。**（8 组 × 8 位的解法由决策侧连错三次后采用；双形态并写由执行侧补充采纳）
**⇒ 哈希比对三分法（可机械执行，采纳自执行侧实测读法）**：
```
  候选串长度 ≠ 64（SHA256）/ ≠ 16（sha16）   ⇒ 判「候选串非法」（不得据此判被测文件变化）
  与实测差异位数 ≤ 2 且同侧                  ⇒ 判「对方笔误」（雪崩效应下内容变化不可能只差 1–2 位）
  与实测差异位数 ≥ 3                         ⇒ 判「候选串非法或内容真变」⇒ 转人工：
                                              从取数输出重新复制，不得继续用候选串比对
```
**⇒ 判据来源**：本批实测正好落在第三类（62 位、8 处差异）⇒ 执行侧报「**候选串非法**」而**不是**「文件变了」——**这个区分是本条的价值所在**。 | **决策侧第 13~19 次**（**同一根因连续复发**：第 13/14 次为手打统计与手打时点；第 15/16/19 次为**同一个 SHA256 连错三次**（第 6 位 `B`→`E`；漏两位成 62 位；再次凭记忆重抄错串）；第 17 次「标 6 列 5」；第 18 次沿用已过期读数。**⇒ 62 位串与含小写的串，应在写入时立即被拒。**） |
| 21 | **每份报告 / 每次执行开头必须有「量具声明块」五要素**：**量具**（命令或函数语义） · **范围**（被测集合的显式定义，含锚点） · **时点**（本步之前 / 之后） · **分母**（**本机实测值**；取自他方文书时**显式标注「来自提单声明，未实测」并同时报实测分母**） · **解析**（正则 / 剥离规则；先剥离 ANSI 再以终止锚定符抓数；**未命中 ⇒ 报「未取到数」**）。**⇒ 五要素缺任一 ⇒ 该项读数标「不可判定」，不折通过、不折失败、不阻断其余项。** | **为让任一第三方（含下一批的决策侧）只凭报告即可复算出同一读数，不依赖执行者的临场判断。**（本条由执行侧提出并采纳：**它的实用性已被本轮三次拦截实证**） |

### 4.4 禁止事项
1. **只读**：工具不得修改任何被检查文件（前后 SHA256 必须一致，TC-11）。
2. **不得在任何输出里写死结论文字**（TC-07）。
3. **不得把"脚本没报错"当作"判据跑过"的证据**（第 12 例）。
4. **不得使用 `git show` + join 计行**（第 15 例）。
5. **不得依赖 PowerShell 格式化**（第 15 例第三次复发）。
6. **不写入项目外目录以外的任何临时位置**；临时文件统一写项目外临时目录且用完即删。
7. **禁止用「截断文本」做归属判定**（如列表页被截断的标题、被 `head -c` 截断的字符串）—— **归属判定必须以结构化字段为准**（如 CI 的 `head_sha`）；**无结构化字段时应判「未取到数」，不得用模糊/前缀比对替代**。
   **依据（2026-09-12 实测）**：执行侧用 `commit subject` 与**列表页被截断的标题**做前缀比对 ⇒ 归属判定 = `False`，**而真实归属由 API `head_sha == 97a15e9` 直接证明**。**内容是对的，判据方法是错的**（同第 17 例家族：判据自身不可信）。

  kind: contains

  text: 立法同族第 17 例

  cross_check_file: .trae/governance/SessionCommands.md   # 第 16 例：须同时报该文件的候选数

  file: .trae/CHANGELOG.md
  lines: 1130
  measure: readalllines                 # 量具定义（第 15 例口径）：行数 = ReadAllLines 语义
  h2: 93
  fences: 0
  fence_measure: indent_aware           # 量具定义：围栏 = 行首允许前导空白的 ``` 行数（含缩进围栏）
```
**⇒ `measure` / `fence_measure` 缺失时，工具必须拒绝执行该判据**（第 15 例第三次复发的直接对策）。
**⇒ 所有 `file` / 工作流名 / 归属标签取自同一份规范化表（§4.3 第 13 条）**；表外取值一律拒绝。
**⇒ 判据文件本身不合法**（缺 `match`、缺 `algorithm`、`id` 重复、枚举外取值）⇒ **退出码 3，且不得执行任何判据**。

### 4.6 输出与退出码
| 退出码 | 含义 |
|---|---|
| `0` | 全部「通过」（且无「未取到数」；或已显式 `--allow-unknown`） |
| `1` | 至少一项「未通过」 |
| `2` | 无「未通过」，但存在「未取到数」且**未**加 `--allow-unknown` |
| `3` | 判据文件本身不合法（**未执行任何判据**） |

**⇒ 汇总段格式（内容必须由测量结果生成）**：
```
判据 N 项 · 通过 A · 未通过 B · 未取到数 C · 不成立 D      ← 全部由测量填充
⇒ 结论：<由 A/B/C/D 机械推出，禁止写死>
```

## 7. 测试用例（**决策侧设计，执行侧执行** —— `AGENTS.md` 规则 15）

| # | 用例 | 期望 |
|---|---|---|
| **TC-01** | 对**不存在的文件**下一条 `contains` 判据 | 输出「**未取到数**」；退出码 `2`；**不得**输出"通过"或"未通过" |
| **TC-02** | `contains` 一条**必然 0 候选**的串（可满足性前置） | 判「**判据不成立**」而非「未通过」；退出码 ≠ 1；报告中给出候选数 = 0 |
| **TC-03** | 判据**缺 `match` 字段** | 退出码 `3`；**其余判据一条都不执行** |
| **TC-04** | 目标串被**反引号 / 加粗**包裹 | 判**命中**；三口径（原样 / 去反引号 / 去行内标记）**分别打印** |
| **TC-05** | 构造一条**两种算法结果不同**的计数判据 | 报「**不一致**」；**不得取其一**；退出码 ≠ 0 |
| **TC-06** | 对**以 LF 结尾**的文件计行 | 采用 `ReadAllLines` 语义值（比 `-split` 少 1）；报告标注所用口径 |
| **TC-07** | 注入一条「未通过」 | **汇总段随之变化**；**不得出现写死的"全部通过"文本** |
| **TC-08** | 归属标签取**枚举外**的值 | **立刻抛错**（不得落 default 分支、不得判未通过） |
| **TC-09** | 三种情形各跑一次 | 退出码分别为 `0` / `1` / `2`，与 §4.6 一致 |
| **TC-10** | 「未取到数」存在但**不加** `--allow-unknown`；再加一次 | 不加 ⇒ 退出码非 0（fail-closed）；加了 ⇒ `0`，**且报告仍保留该态计数** |
| **TC-11** | 跑完工具后对被检查文件算 SHA256 | **与跑前逐字节相同**（工具只读） |
| **TC-12** | 在**项目外干净浅克隆**内跑同一条判据 | 结论与本机一致（**"只在开发机跑绿即宣称通过"= 无效声明**） |
| **TC-13** | 构造"某条目被 skip，且该 skip 分支位于报告段之前"的场景 | **报告段仍必须非空**；**工具在每条退出路径上都必须输出报告段**；**不得出现"应报项存在但报告为空"**（第 18 例） |
| **TC-14** | 构造一个「取数函数返回 `null` / 空串 / 空集合」的场景 | **必须抛错**（fail-closed）；**不得输出 `0` / 空串 / 空集合当作读数**；**报告段与结构段的每个数值须可追溯至一次非空取数**（第 19 例） |
| **TC-15** | 构造一个「取数函数返回一个被额外包裹的集合（如 `@( @(a,b) )`）」的场景，以及一个「某条判据未产出判定」的场景 | **① 形状异常 ⇒ 必须抛错，不得把多元集合静默报告成 `1`**；**② 判据门须自断言：应产出判定条数 ≠ 实际打印判定条数 ⇒ 该门视为无效 ⇒ 停手并报告**（第 20 例） |
| **TC-16** | 构造一个「未声明时点的取数」场景，以及一个「外部命令输出含 ANSI 转义 / 返回多值」的场景 | **① 未声明时点的读数 ⇒ 判「不可采信」并拒绝出结论**（含 `at` 缺失 ⇒ 整份文件不合法、退出码 3、不执行任何判据）；**② 输出必须先剥离 ANSI 并显式类型转换 ⇒ 不得出现空值伪读数或 `System.Object[]`**。**③ 跨提交 / 跨状态统计必须先固定并写出比较基准**（父提交、基线 SHA 或范围端点），**未声明比较基准的读数不采信**（第 21/22 例）；**④ 抓数正则必须带终止锚定符**（数字后紧跟单位 / 分隔符），**禁止用 `.` 通配跨越转义序列** |
| **TC-17** | 构造一个「某值只有前 16 位是实测的、其余位是凭字形补全的」场景 | **必须判「不可采信」并拒绝出结论**；**不得把补全值当成读数**；**补全值与实测值必须可区分**（第 23 例） |
| **TC-18** | 构造一次「文书内部标称分组数 ≠ 实际列出条数」的场景，以及一次「哈希长度非法（如 62 位）」的场景 | **① 分组计数之和 ≠ 总数 ⇒ 判「文书自不一致」并拒绝**；**② 哈希长度非法 ⇒ 判「格式自断言失败」并拒绝**（第 20 条） |

**⇒ 上线判据**：**TC-01 ~ TC-12 全绿**方可执行 §5.1 / §5.2 挂钩。**任一不绿 ⇒ 挂钩不做。**
