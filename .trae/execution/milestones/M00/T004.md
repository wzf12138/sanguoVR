# T004 动画与全身 IK 基线

## 目标

确认动画状态来源、Montage/Notify 边界、线程安全、LOD 和全身 IK 降级策略。

## 白名单

- `.trae/standards/AnimationArchitecture.md`
- `.trae/vr/FullBodyIKStandard.md`
- `.trae/systems/AnimationSystem.md`
- Animation Blueprint、Montage、IK Rig、Retargeter、Control Rig 的只读检查

## 禁区

- 不保存或重编译动画资产。
- 不批量重定向骨架、不修改骨骼层级或动画压缩设置。
- 不修改 Gameplay 真值或命中判定。
- 不执行 Git 命令。

## 步骤

1. 绘制 Gameplay 状态到动画快照再到姿态输出的数据流。
2. 核对状态机条件、Montage Slot、打断和 Notify 用途。
3. 核对 HMD/控制器坐标转换、标定、人体约束与跟踪降级。
4. 识别动画线程、每帧 Cast、Control Rig 与 IK 性能风险。

## 测试

- Locomotion、战斗、受击、抓取和跟踪丢失均有转换用例。
- 骨盆、肩肘、腿脚在极限姿态下无翻折通过标准。
- LOD 与不可见角色更新策略可验证。
- 性能用例能对应 Pico Neo 3 动画/IK 预算。

## 停止条件

- 评估工具要求写回资产。
- Skeleton 或 Retarget 链存在损坏，继续操作可能扩大影响。
- 缺少必要跟踪输入且无法用记录数据替代。

## 回退

删除 `.trae/execution/reports/M00/T004/` 下生成物；任何意外打开的资产不保存并关闭编辑器。
