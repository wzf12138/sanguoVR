# T001 项目与工具链基线

## 目标

确认 Unreal 项目、Android/Pico Neo 3 工具链和基础目录可用；Git 保持待安装，不执行任何 Git 操作。

## 白名单

- `.trae/**`
- 项目描述文件与只读配置检查
- Unreal Editor、Unreal Automation Tool 的版本和可用性检查
- Android SDK/NDK/JDK/Pico 插件的只读状态检查

## 禁区

- 不修改 `.trae` 之外文件。
- 不安装、初始化、配置或运行 Git；状态固定为“Git：待安装”。
- 不升级引擎、插件、SDK，不修改系统环境变量。
- 不删除 `Content`、`Config`、`Source` 或生成目录。

## 步骤

1. 记录项目根、`.uproject`、引擎版本与目标平台。
2. 读取 Android、OpenXR/Pico 插件和打包工具状态。
3. 记录缺失依赖及其阻断范围，不自行安装。
4. 建立 M00 报告目录并写基线结果。

## 测试

- 项目描述文件可解析。
- 编辑器命令行可返回版本；若不可用，记录错误而不修复系统。
- Android 工具链检查结果包含版本或明确缺失项。
- 报告中存在“Git：待安装，未执行”。

## 停止条件

- 目标路径与请求项目不一致。
- 检查需要管理员权限、联网安装或修改 `.trae` 外文件。
- 项目或引擎文件读取出现损坏迹象。

## 回退

仅删除本任务在 `.trae/execution/reports/M00/T001/` 新建的报告；不触碰项目文件与工具链。

## 报告路径

`.trae/execution/reports/M00/T001/report.md`
