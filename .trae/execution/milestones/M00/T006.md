# T006 Pico Neo 3 性能、测试与遥测基线

## 目标

建立可复现的 Pico Neo 3 性能采样、自动化测试和调试/遥测合规基线。

## 白名单

- `.trae/vr/PicoNeo3PerformanceBudget.md`
- `.trae/standards/TestingStandard.md`
- `.trae/systems/AudioSystem.md`
- `.trae/systems/DebugAndTelemetry.md`
- 只读性能捕获、自动化测试与本地日志输出

## 禁区

- 不修改引擎、设备性能档位、系统温控或发行配置。
- 不上传遥测，不记录个人信息、凭据或原始用户内容。
- 不以 PC VR Preview 数据代替真机结论。
- Git 为待安装；不执行任何 Git 命令。

## 步骤

1. 固定设备、刷新率、构建配置、场景、角色数和测试时长。
2. 采集帧时、Game/Render/GPU、内存、温度与掉帧段。
3. 运行可用的单元、功能、地图与生命周期测试。
4. 检查日志类别、级别、敏感字段、遥测开关和离线队列上限。
5. 汇总阻断项、预算超限项和不可验证项。

## 测试

- 真机连续运行至少 20 分钟并记录 P50/P95/P99。
- 90 Hz 模式对照 11.11 ms 总帧预算；72 Hz 单独标识。
- 自动化失败保留原始日志，不通过重复运行隐藏。
- 关闭遥测后无网络请求；日志无每帧刷屏与敏感数据。

## 停止条件

- 设备过热、系统告警、崩溃循环或内存接近系统终止线。
- 捕获需要修改 `.trae` 外文件或上传外部服务。
- 构建配置、刷新率或场景不明确，数据不可比较。

## 回退

停止测试应用，清理本任务本地捕获与 `.trae/execution/reports/M00/T006/` 输出；不更改设备系统设置。
