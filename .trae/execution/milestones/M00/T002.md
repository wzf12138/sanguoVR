# T002 编码、蓝图与命名基线

## 目标

用精确标准建立 C++、蓝图和 Unreal 资产命名的只读评估基线。

## 白名单

- `.trae/standards/CppCodingStandard.md`
- `.trae/standards/BlueprintStandard.md`
- `.trae/standards/UnrealNamingStandard.md`
- `Source/**`、`Plugins/**/Source/**` 与 Content 资产清单的只读扫描

## 禁区

- 不自动重命名资产、修复 Redirector 或改写源码。
- 不编译、保存关卡或重新序列化二进制资产。
- 不扫描引擎安装目录作为项目缺陷。
- 不执行 Git 命令。

## 步骤

1. 读取三份标准并提取可判定规则。
2. 扫描源码命名、Include、日志类别和高风险 Tick 模式。
3. 扫描资产前缀、路径、临时命名和 Redirector 风险。
4. 按阻断、严重、一般分类记录证据与建议。

## 测试

- 每条发现包含规则、路径、证据和严重级别。
- 抽样复核 C++、Blueprint、Widget、输入和动画资产命名。
- 报告区分确定违规与需编辑器验证项。

## 停止条件

- 扫描工具将写入或保存资产。
- 资产注册表不可读取，继续扫描会产生大量误报。
- 发现项目路径越界或符号链接指向白名单外。

## 回退

删除 `.trae/execution/reports/M00/T002/` 下本次报告和缓存；源文件与资产不应发生变化。
