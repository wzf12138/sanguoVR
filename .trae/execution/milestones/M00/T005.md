# T005 存档、本地化与 UI 基线

## 目标

评估存档版本/恢复、本地化文本链路和 VR UI 生命周期的完整性。

## 白名单

- `.trae/standards/SaveSystemStandard.md`
- `.trae/standards/LocalizationStandard.md`
- `.trae/systems/SaveSystem.md`
- `.trae/systems/LocalizationSystem.md`
- `.trae/systems/UISystem.md`
- 存档类、String Table、Gather 配置和 Widget 的隔离测试

## 禁区

- 不覆盖真实玩家存档，不执行不可逆迁移。
- 不导入外部翻译、不改源语言、不批量保存 Widget。
- 不把测试文件写入平台正式存档槽。
- 不执行 Git 命令。

## 步骤

1. 记录存档分区、稳定 ID、格式版本、备份和原子写入策略。
2. 在隔离槽定义往返、损坏、截断、旧版本和磁盘失败测试。
3. 检查玩家可见文本来源、Key 稳定性、格式参数与字体覆盖。
4. 检查语言切换后 UI、字幕和输入提示刷新路径。

## 测试

- 存档失败不覆盖最后有效文件，迁移失败保留源文件。
- `zh-Hans` 与 `en` 的 Gather/Cook/显示用例齐全。
- 菜单重复开关、切关、暂停恢复无实例或焦点泄漏。
- 报告不包含真实用户数据或完整存档内容。

## 停止条件

- 无法建立隔离槽或测试会接触正式数据。
- 本地化 Gather 将改写未授权文件。
- 检测到存档结构未知且无版本标识。

## 回退

删除隔离测试槽和 `.trae/execution/reports/M00/T005/` 输出；正式存档与本地化资源保持不变。
