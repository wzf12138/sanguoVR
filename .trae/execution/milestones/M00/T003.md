# T003 VR 输入、交互与舒适性基线

## 目标

评估 Enhanced Input、手部/物体交互、VR UI 与移动舒适性是否形成可测试闭环。

## 白名单

- `.trae/standards/EnhancedInputStandard.md`
- `.trae/vr/VRUIUXStandard.md`
- `.trae/vr/HandAndObjectInteraction.md`
- `.trae/vr/ComfortAndLocomotion.md`
- 输入、交互、UI 和 VR 设置资产的只读检查

## 禁区

- 不修改 Mapping Context、Input Action 或玩家默认设置。
- 不连接、更新或重置 Pico 设备。
- 不改变 Guardian、系统按键或平台权限。
- 不执行 Git 命令。

## 步骤

1. 建立 Gameplay、UI、Paused、Cinematic 输入上下文矩阵。
2. 核对抓取状态、所有权仲裁、跟踪丢失和安全释放路径。
3. 核对传送、转向、坐姿/站姿、主手与舒适选项。
4. 记录需要 VR Preview 与 Pico Neo 3 真机验证的用例。

## 测试

- 左右手、按下/保持/释放、断连重连用例齐全。
- UI 射线与世界交互焦点冲突有预期结果。
- 传送落点、Snap Turn、Smooth 模式与暂停恢复有测试定义。
- 每项真机测试包含观察指标和通过标准。

## 停止条件

- 测试会修改玩家持久设置且无法隔离。
- 需要未授权设备操作或平台账号登录。
- 当前构建不能启动 VR 且原因未明确。

## 回退

恢复测试前记录的本地 VR 设置；删除 `.trae/execution/reports/M00/T003/` 中本次输出。
