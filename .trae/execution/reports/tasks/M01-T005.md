## 偏差与变更清单

1. **标注语言**：TASK.md 要求中文标注（"出生点"等），实际使用英文（`PLAYER SPAWN` / `AI SPAWN` / `COVER` / `PLATFORM`）。原因：项目尚无中文字体资产，`TextRenderActor` 默认 Roboto 无法渲染中文。中文标注待中文字体资产引入后补加。
2. **GameMode**：`BP_VRGameMode`（M00-T005 产出）未就绪，按任务约定使用模板默认 `/Game/VRTemplate/Blueprints/VRGameMode`；T005 完成后可切换。
3. **NavMesh 构建方式**：Python API 未暴露 `NavigationSystemV1.build()`，改用编辑器控制台命令 `BuildPaths` 触发静态构建（日志确认成功），替代"Project Settings -> Navigation -> Build"菜单操作。
4. **光照烘焙（Lightmass）**：未执行。无头编辑器环境下 Zen Server/DDC 无写入节点（沙箱路径权限受限，引擎启动即崩溃），Lightmass 静态烘焙需在编辑器 GUI 会话执行；灰盒关卡当前使用动态光照（Movable），PIE 渲染正常。
5. **斜坡方向**：`SM_Ramp` 按 yaw=90 放置（假设模板坡向 +X -> +Y，高端接平台），需编辑器目视确认；若方向相反仅需旋转 180°。
6. **MapCheck 警告**：`SM_ChamferCube`/`SM_Ramp` 使用 Nanite 但项目未启用 Virtual Shadow Maps（仅影响静态光阴影质量，不影响灰盒测试）。启用 VSM 或关闭 Nanite 涉及 `Config/`，超出白名单，建议后续变更申请处理。
7. **PIE/真机性能**：`stat fps` >= 90fps 需编辑器 PIE 或 PICO 真机验证，当前无头环境不可执行，标记待验证。
