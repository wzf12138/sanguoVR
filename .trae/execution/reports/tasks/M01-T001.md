## 2026-08-26 复盘：关卡 Lit 全黑修复

### 根因

`L_SkeletonTest` 关卡在 Lit 模式下全黑，但 Unlit 模式可见几何体（地板 + 两个叠放方块），说明是照明问题而非几何体缺失。经逐项核查，两处根因：

1. **定向光方向错误（主因）**：`DirectionalLight` 的朝向向量 `fwd=(0.94, 0.00, 0.34)`，Z 分量为 **正**，即光束朝**上方/水平**照射，等于从地板下方往上打，地板顶面（法线 +Z）永远照不到 → Lit 全黑。而官方 `VRTemplateMap` 的定向光 pitch=-38.3（光从上往下），因此模板正常。
2. **天光为静态且未捕获**：`SkyLight` 的 `real_time_capture=False`、intensity=1.0，且场景无烘焙光照，等于没有环境补光。

### 修复

| 项 | 修改前 | 修改后 |
|----|--------|--------|
| DirectionalLight 朝向 | fwd Z=+0.34（朝上） | pitch=-45°，fwd Z=-0.71（光向下） |
| DirectionalLight 位置 | (0,0,0) 与地板同行 | (0,0,1000) 置于上方 |
| DirectionalLight 强度 | 8.0 | 3.0 |
| DirectionalLight 大气太阳光 | True（保留） | True |
| DirectionalLight 静态性 | — | 设为 Movable（无需烘焙即可受光） |
| SkyLight 实时捕获 | False | True |
| SkyLight 强度 | 1.0 | 1.0 |
| SkyLight 静态性 | — | 设为 Movable |

- 天光持久化为 `rt=True`、int=1.0（`PERSIST4_SL`）。

## 实施步骤

### Step 1：确认 VRE 编译状态 ✓

- VRExpansionPlugin 5.4 已编译通过
- Binaries/Win64/ 目录包含编译后的 DLL
- 插件已启用（EnabledByDefault: true）

### Step 2：创建武器抓取蓝图基类 ✓

- 在 `Content/VRSanguo/VR/` 创建 `BP_WeaponBase`
- 继承 `GrippableSkeletalMeshActor`
- 添加 `bAllowSecondaryGrip` 变量（默认true）

### Step 3：配置 HandSocket 握持姿势 ✓

- 添加 `HandSocket_Primary` 组件
  - SlotPrefix: "Primary"
  - bFlipForLeftHand: true
  - bLeftHandDominant: true
  - HandRelativePlacement: [0, 0, 0]
- 添加 `HandSocket_Secondary` 组件
  - SlotPrefix: "Secondary"
  - bFlipForLeftHand: true
  - bLeftHandDominant: false
  - HandRelativePlacement: [0, -20, 0]

### Step 4：创建测试武器 ✓

- 基于 `BP_WeaponBase` 创建 `BP_TestSword`
- 添加 `WeaponMesh` 组件（StaticMeshComponent）
- 设置 StaticMesh: /Engine/BasicShapes/Cube
- 设置 Scale3D: [0.1, 0.1, 1.0]

### Step 5：放置到关卡 ✓

- 打开 `L_SkeletonTest` 关卡
- 在位置 [0, 0, 100] 放置 TestSword_01
- 保存关卡
