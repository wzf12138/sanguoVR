## 目标

利用 VRE（VRExpansionPlugin）的 `GripMotionControllerComponent` + `HandSocketComponent` 建立 VR 手部物理抓取武器的基础能力。不替换现有 VRPawn，以组件方式集成 VRE 抓取系统。

## 实施步骤

### Step 1：确认 VRE 编译状态 ✓

- VRExpansionPlugin 5.4 已编译通过
- Binaries/Win64/ 目录包含编译后的 DLL
- 插件已启用（EnabledByDefault: true）

### Step 2：创建武器抓取蓝图基类 ✓

- 在 `Content/VRSanguo/VR/` 创建 `BP_WeaponBase`
- 继承 `GrippableSkeletalMeshActor`
- 添加 `bAllowSecondaryGrip` 变量（默认true）

### Step 3：配置 HandSocket 握持姿势 ✓

- 添加 `HandSocket_Primary` 组件
  - SlotPrefix: "Primary"
  - bFlipForLeftHand: true
  - bLeftHandDominant: true
  - HandRelativePlacement: [0, 0, 0]
- 添加 `HandSocket_Secondary` 组件
  - SlotPrefix: "Secondary"
  - bFlipForLeftHand: true
  - bLeftHandDominant: false
  - HandRelativePlacement: [0, -20, 0]

### Step 4：创建测试武器 ✓

- 基于 `BP_WeaponBase` 创建 `BP_TestSword`
- 添加 `WeaponMesh` 组件（StaticMeshComponent）
- 设置 StaticMesh: /Engine/BasicShapes/Cube
- 设置 Scale3D: [0.1, 0.1, 1.0]

### Step 5：放置到关卡 ✓

- 打开 `L_SkeletonTest` 关卡
- 在位置 [0, 0, 100] 放置 TestSword_01
- 保存关卡

  - SkeletalMeshComponent0 (根组件)
  - HandSocket_Primary (HandSocketComponent)
    - SlotPrefix: "Primary"

    - bLeftHandDominant: true

    - SlotPrefix: "Secondary"
    - bFlipForLeftHand: true
