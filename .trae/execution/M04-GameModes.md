# M04 三类模式与本地存档

## 目标

把战斗系统包装为生涯、自定义对战和训练三类正式离线内容。

## 交付

- 生涯章节、赛事推进、横向解锁、标准团队战和武将挑战入口。
- 自定义对战的场地、2v2—4v4、阵容、兵种、武将、难度、胜利条件、脱手和移动辅助配置。
- 训练覆盖校准、两种移动、五武器、护甲、脱手恢复、兵种应对、队友命令和 N 对 N 练习。
- 三类模式的准备、暂停、结算、重开、返回和统计。
- 设置、进度、预设和统计的本地存档，支持断网冷启动。

## 退出条件

新存档可从主菜单进入三类模式并完成一局；异常退出后进度可恢复；任何正式内容不依赖控制台、账号或服务器。
