## 关键决策

1. 抓取方案采用 **mesh socket**（VRE 官方示例剑同款），而非 HandSocketComponent 子组件，因 socket 随网格
   走、`GetAllSocketNames` 自动识别，最稳。
2. 直接使用**原生 `AGrippableStaticMeshActor`** 而非 BP 子类，规避 BP 组件编辑的 Python SCS 复杂性。
3. 剑柄定位以 **OBJ 顶点分布实测**为准（此前凭「负端顶点少即剑柄」的经验判断放反了），结论：剑柄在
   **正 X 端**，握点应置于护手与环首之间的剑柄杆区（主手 X+9、副手 X+18）。
4. 用户明确「能抓整把剑还是指定握持点」→ 保持指定握持点（真实手感）；后续可按用户诉求切换自由抓取。
