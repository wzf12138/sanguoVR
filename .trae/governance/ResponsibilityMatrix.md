# 职责边界

| 角色 | 负责 | 不得自行决定 |
|---|---|---|
| 用户/项目所有者 | 批准范围、优先级、风险、发布和破坏性变更 | 无 |
| AI/开发代理 | 读取事实源、实施已批准任务、验证、更新登记册 | 擅自改变产品范围、伪造验证、绕过权限治理 |
| UE 编辑器/构建工具 | 生成工程产物、编译、Cook、打包、日志 | 产品与治理决策 |
| Git | 版本历史、差异、回滚锚点 | 运行时正确性与设备体验 |
| 管理员脚本 | 应用/检查/恢复 NTFS ACL | 自动替代用户管理员授权 |

所有代理开始工作前必须读取 `.trae/README.md`、`.trae/rules/project_rules.md` 和任务对应事实源。
