# 规则 ⇄ 门禁 映射（VRSanguoYanWuchang）

**性质**：`AGENTS.md` 规则正文与 `dashboard/check-integrity.py` 门禁项的**覆盖关系表**。**唯一目的**：让"哪条规则由机器守、哪条只靠人守"可查、可计数。

**用法**：
1. **新增规则时，必须同时在本表登记一行** —— 未登记 = 该规则没有执行路径。
2. **改门禁项时，同步本节「门禁项」列**。
3. **本表只陈述事实，不写"计划补门禁"之类意向** —— 有就有，没有就没有。

**执行者取值**：

| 取值 | 含义 |
|---|---|
| **机器** | 有门禁项**完整**覆盖，违反即 `EXIT != 0` |
| **半机** | 有门禁项**部分**覆盖（覆盖了该规则的一个子集） |
| **人守** | **无任何门禁项覆盖**，违反只能靠人发现 |

**当前计数**：**机器 2 条 · 半机 6 条 · 人守 24 条**（共 32 条）。门禁共 **30 项**，其中 **12 项**不映射任何规则（见文末）。

## 不映射任何规则的门禁项（12 项）

这些项检查的是**项目结构事实**或**门禁自指**，不对应某条行为规则，但对整体一致性有效：

| 门禁项 | 检查什么 |
|---|---|

| `pattern_library` 文件数 | 集合计数 |

| 必需目录使用 `index.md` | 目录约定 |
| integrity.yaml 链接计数一致 | 门禁自指 |
| CHANGELOG 不滞后于提交 | 文书与提交时间一致性 |
| open 技术债 ≤ 3 | 自定阈值 |
