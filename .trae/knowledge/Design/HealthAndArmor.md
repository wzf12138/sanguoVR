# 生命与护甲详规

## 数据模型

角色只有一个统一生命池。头、躯干、左右臂、左右腿等命中区记录护甲覆盖、抗性、命中倍率和反馈标签，不记录独立生命。

```text
CharacterHealth
├─ CurrentHealth
├─ MaxHealth
└─ State

ArmorProfile
└─ HitZones[]
   ├─ Coverage
   ├─ ResistanceByDamageType
   ├─ HitModifier
   └─ FeedbackTag
```

## 规则

- 命中区查询护甲后，将最终伤害扣到统一生命。
- 手臂或腿部命中可触发短时动作影响，但不能形成永久独立残肢生命系统。
- 护甲没有耐久、破损、修理、受击衰减或隐藏损耗字段。
- 血迹、凹痕、火花和贴花只负责反馈，不改变防护数据。
- 武将与普通兵使用同一结算模型，差异来自配置、动作与决策质量。

## 状态

生命系统至少支持正常、短时失衡、濒危表现、死亡和重置。模式重开必须清空临时状态并恢复对应配置，不残留上局护甲或硬直数据。
