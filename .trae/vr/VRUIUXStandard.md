# VR UI/UX 标准

## 空间与可读性

- 主要面板默认位于视线前方约 1.0–2.0 米，避免贴脸、过远或跟随头部产生漂移感。
- 关键文本按真机角分辨率验证；不以桌面 DPI 或编辑器预览判断可读性。
- 世界空间 UI 使用清晰层级、足够对比度和稳定背景，避免细线、闪烁与高频透明叠加。
- 面板出现时不得突然遮挡双眼中心或穿过玩家身体。

## 交互

- 射线、近触、凝视三类输入共享一致的 Hover、Pressed、Disabled 与 Confirmed 反馈。
- 可点击目标保留足够命中面积和间距；小图标必须扩大交互区域而非只放大视觉。
- 焦点由 UI 与世界交互仲裁；打开菜单时不得误触背后物体。
- 危险、不可逆或退出操作需要二次确认；常用操作避免重复确认。
- 提供主手切换、字幕、音量、转向方式、移动方式和高度校准入口。

## 反馈与舒适

- 输入后 100 ms 内出现视觉或触觉反馈；耗时操作显示非阻塞进度状态。
- 避免跟头 HUD 长时间固定在中心；必要信息放在稳定世界锚点或按需唤出。
- 错误提示说明发生事项与恢复方法，不依赖颜色单独传达状态。

## 测试

- 站姿、坐姿、不同身高、左右手、弱视/色觉差异与控制器抖动场景均需覆盖。
- Pico Neo 3 真机检查字体、射线精度、按钮误触、面板裁剪与帧率影响。
