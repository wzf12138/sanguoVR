# 全身 IK 标准

## 输入与标定

- 输入至少包含 HMD、左右控制器与角色根；额外跟踪器作为可选能力，不得成为基础流程硬依赖。
- 初次进入和身高变化时完成身高、臂展、肩宽与地面标定，并允许用户重置。
- 所有跟踪姿态统一到角色坐标空间，明确世界缩放、玩家朝向和 Tracking Origin。

## 求解顺序

1. 确定胶囊与虚拟根位置。
2. 求解头部、胸腔与骨盆朝向。
3. 求解左右臂和手腕。
4. 基于骨盆与移动状态求解腿部、脚底和地面贴合。
5. 应用关节限制、自碰撞近似与最终平滑。

## 约束

- 肩、肘、腕、髋、膝使用人体合理角度限制，禁止因目标不可达而翻折。
- 手目标超出臂长时使用肩部补偿或软拉伸，骨骼缩放必须有上限。
- 坐姿、蹲姿、转身和侧倾不能让骨盆穿过地面或腿部持续交叉。
- 跟踪置信度下降时逐步混回动画姿态；恢复时平滑接管。
- 镜像、本地身体和远端 Avatar 应使用同一标定数据源，但可采用不同更新频率。

## 性能

- 求解频率、LOD 和可见性驱动更新；不可见远端角色不得保持完整 Control Rig 成本。
- Pico Neo 3 上本地全身 IK CPU 预算遵循性能预算文档，超限时先降低次要约束和远端更新率。

## 测试

- 覆盖不同身高、坐姿、蹲下、手交叉、手背后、快速转头、边界外和跟踪丢失。
