# Pico Neo 3 性能预算

## 帧预算

- 目标刷新率为 90 Hz 时，单帧总预算为 11.11 ms；稳定性不足时不得以偶发平均值宣称达标。
- Game Thread、Render Thread、GPU 任一持续超过 10.5 ms 即进入风险区；以 0.6 ms 作为系统波动余量。
- 若产品明确采用 72 Hz，单帧预算为 13.89 ms，仍需记录模式与理由，不得混用指标。

## 建议分配

| 项目 | 90 Hz 预算 |
| --- | ---: |
| Game Thread | ≤ 4.0 ms |
| Render Thread/RHI | ≤ 3.5 ms |
| GPU | ≤ 10.5 ms |
| 动画与 IK（CPU） | ≤ 1.5 ms |
| UI（CPU+GPU 增量） | ≤ 1.0 ms |
| 音频游戏线程增量 | ≤ 0.5 ms |

## 资源预算

- 运行时内存目标 ≤ 2.8 GB，峰值告警线 3.2 GB；以真机系统可用内存验证。
- 常驻纹理、网格、动画和音频由场景清单控制，禁止无界软引用批量加载。
- Draw Calls、可见三角形、透明层数按最坏战斗场景实测设限；首次基线前不得凭编辑器估算填数。
- Shader permutation、动态光源、后处理和粒子必须在移动渲染路径验证。

## 采样规则

- 使用 Shipping 或接近 Shipping 的 Android 构建，真机连续运行至少 20 分钟。
- 记录刷新率、CPU/GPU Level、动态分辨率、温度、场景、角色数和特效强度。
- 报告必须包含 P50、P95、P99 帧时、掉帧段、内存峰值和热降频迹象。

## 阻断条件

- 持续掉帧、可见卡顿、热降频后失稳、内存逼近系统终止线或跟踪延迟增加。
- 仅在 PC VR Preview 达标不能视为 Pico Neo 3 达标。
