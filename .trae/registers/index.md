# Registers 文档索引

本目录记录随开发变化、需要持续追踪的项目事实。登记项不替代 [`../knowledge/GameMasterPlan.md`](../knowledge/GameMasterPlan.md)、[`../knowledge/Design/index.md`](../knowledge/Design/index.md) 或 [`../standards/index.md`](../standards/index.md)；它们只记录决定、风险、依赖、追踪关系、资产状态、试玩发现和标准完善待办。

| 文档 | 用途 |
|---|---|
| `01-decision-register.md` | 关键设计与技术决定 |
| `02-risk-register.md` | 风险、触发信号与应对 |
| `03-dependency-register.md` | 引擎、XR、资产和系统依赖 |
| `04-requirement-traceability-register.md` | GameMasterPlan 到验收与系统的追踪 |
| `05-asset-license-register.md` | 第三方与自制资产许可状态 |
| `06-playtest-issue-register.md` | 试玩观察、缺陷和验证结论 |
| `07-task-register.md` | 项目任务状态与交付物 |
| `08-permission-register.md` | NTFS ACL 目标策略与应用状态 |
| `09-verification-register.md` | 验证层级、状态与证据 |
| `10-asset-register.md` | 资产登记册 |
| `11-tech-debt-register.md` | 技术债登记与偿还追踪 |
| [`standards-backlog.md`](standards-backlog.md) | M00-M06 标准完善待办、触发条件与完成定义 |

登记状态按对应登记册约定维护，每次变更保留日期、责任角色和证据链接。
