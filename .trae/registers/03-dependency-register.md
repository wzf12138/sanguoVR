# 依赖登记

| ID | 依赖 | 用途 | 当前要求 | 替代/风险 |
|---|---|---|---|---|
| DEP-001 | Unreal Engine 5 | 运行时与编辑器 | 锁定项目版本并记录升级测试 | 升级可能改变物理、XR 与构建 |
| DEP-002 | OpenXR | 头显与控制器抽象 | 使用语义输入动作 | 厂商扩展仅在必要时启用 |
| DEP-003 | 目标一体机 SDK/运行时 | 打包、性能、权限 | 记录系统版本与刷新率 | 不以 PC VR 测试替代 |
| DEP-004 | UE 行为树/黑板或等价 AI 框架 | 感知与动作编排 | 战术评分保留可调层 | 避免随机行为树失控 |
| DEP-005 | Data Asset/Data Table | 武器、AI、教程配置 | 稳定 ID、版本与校验 | 禁止复制蓝图代替数据变体 |
| DEP-006 | 动画与角色骨骼 | AI 战斗表现 | 尽量复用统一骨骼 | 来源混杂导致重定向成本 |
| DEP-007 | 音效与触觉资源 | 命中、格挡、受击反馈 | 结果类型可区分 | 缺失时使用占位映射 |
| DEP-008 | 第三方美术资产 | 校场、角色、武器 | 商业许可、LOD、碰撞、性能审查 | 不合规则灰盒或自制替代 |
| DEP-009 | Git | 版本控制与回滚锚点 | 本轮不安装、不执行；启用后遵循 `../standards/10-git-standard.md` | Git 基线前禁止批量覆盖无法人工复核的长文档 |

具体版本、来源、责任人、许可证和验证日期在依赖确定后补录，不得凭空标记为已验证。
