## 资产级依赖链

以下为里程碑级资产依赖关系，决策模型创建资产任务时据此确定任务的"前置依赖任务"字段。依赖不满足时，任务不得设为 `ready`。

### M01 1v1 核心战斗切片

```
角色骨架 (SK_Militia)
  ├─→ 角色动画 (A_Militia_*)     ← 依赖骨架
  ├─→ 武器模型 (SK_Sword 等)     ← 依赖骨架（挂载点）
  │     └─→ 武器动画 (A_Sword_*)  ← 依赖武器模型 + 角色骨架
  └─→ 护甲模型 (SM_Armor_*)      ← 依赖骨架（挂载点）

竞技场灰盒 (L_Prototype_Symmetric)
  └─→ NavMesh 生成               ← 依赖关卡布局

战斗系统核心 (C++)
  └─→ 武器 DataAsset (DA_Weapon_*) ← 依赖战斗系统接口
```

### 通用依赖规则

- **骨骼优先**：任何依赖骨架的资产（动画、武器、护甲）必须等骨架任务 `approved` 后才能设为 `ready`
- **系统优先**：任何依赖 C++ 接口的 DataAsset/Blueprint 必须等系统任务 `approved` 后才能设为 `ready`
- **关卡最后**：关卡任务依赖其包含的所有资产，应排在最后一批创建
- **视觉资产独立**：不依赖同一骨架的资产（如音效、UI、特效）可并行创建

### 并发安全

- 并行任务不得共享同一骨架文件（避免动画和武器同时修改骨架）
- 同一 Content/ 子目录下不得有两个 `in_progress` 任务（避免文件冲突）
- 资产登记册 `10-asset-register.md` 为资产状态唯一权威，认领前必须检查
