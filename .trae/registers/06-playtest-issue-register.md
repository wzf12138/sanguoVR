# 试玩问题登记

## 记录格式

| 字段 | 说明 |
|---|---|
| ID | `PT-YYYYMMDD-NNN` |
| 构建/设备 | 构建号、头显、系统与刷新率 |
| 场景 | 教程步骤、武器、AI 等级、局次 |
| 观察 | 可复现事实，不先写原因 |
| 玩家表达 | 尽量保留原话 |
| 影响 | 阻断、严重、一般、轻微 |
| 假设 | 可能原因，与事实分开 |
| 处理 | 修复、调参、补测或接受 |
| 证据 | 日志、录像、统计、复现步骤 |
| 状态 | 开放、验证中、已关闭 |

## 初始验证主题

| ID | 待验证问题 | 成功信号 | 失败信号 |
|---|---|---|---|
| PT-THEME-001 | 挥砍是否有重量且可控 | 玩家感到命中有后果，仍能恢复武器 | 过轻、过黏或频繁卡死 |
| PT-THEME-002 | 攻击、格挡、受击是否可理解 | 无口头指导可分辨反馈 | 玩家不知为何受伤或格挡失败 |
| PT-THEME-003 | 瞬移是否舒适且有战术价值 | 理解距离/冷却并主动使用 | 眩晕、落点困惑或无限逃逸 |
| PT-THEME-004 | AI 是否公平可读 | 能描述 AI 意图与反击机会 | 认为 AI 读心、瞬防或无视硬直 |
| PT-THEME-005 | 是否愿意再来一局 | 结果后主动重开 | 首局后退出且原因指向核心战斗 |
| PT-THEME-006 | 连续三局是否稳定 | 无状态错乱与性能下降 | 输入失效、残留对象、帧率衰减 |

关闭核心体验问题前必须至少完成一次目标设备外部试玩复验。
