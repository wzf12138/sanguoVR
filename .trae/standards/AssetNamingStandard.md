# 资产命名规范

## 路径

项目自有资产统一位于 `/Game/VRSanguo/`。第三方资产放 `/Game/VRSanguo/ThirdParty/Vendor_Package/`。

## 前缀

- 蓝图：`BP_`
- Actor Component：`BPC_`
- Widget：`WBP_`
- Data Asset：`DA_`
- Data Table：`DT_`
- Static/Skeletal Mesh：`SM_` / `SK_`
- Material/Instance：`M_` / `MI_`
- Texture：`T_`
- Animation/Blend Space/Montage：`A_` / `BS_` / `AM_`
- Niagara：`NS_`
- Sound：`S_`
- Input Action/Mapping Context：`IA_` / `IMC_`
- Map：`L_`

命名使用英文 PascalCase；禁止 `NewAsset`、`Test2`、中文文件名和无意义版本后缀。实验资产放 `Developer/LocalExperiment/<TaskId>/`。
