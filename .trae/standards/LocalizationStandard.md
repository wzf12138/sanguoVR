# 本地化标准

## 文本来源

- 所有玩家可见文本使用 `FText` 或本地化 String Table；禁止用 `FString`/`FName` 承载显示文本。
- C++ 使用 `LOCTEXT`、`NSLOCTEXT` 或 String Table；蓝图文本必须可收集。
- 文本 Key 稳定且表达语义，禁止由中文原文、界面位置或自动递增编号生成。
- 人名、地名、武将称号、兵种、物品和历史术语使用统一术语表。

## 内容规则

- 禁止拼接可见句子；使用带命名参数的格式化文本支持语序变化。
- 数字、日期、时间、复数和性别变化使用区域化格式，不手工拼字符串。
- UI 为中文、英文长度差异预留空间；禁止依赖固定字符数裁切。
- 字体必须覆盖简体中文、拉丁字符、数字与项目使用的标点；缺字视为阻断问题。
- 语音、字幕和提示按稳定内容 ID 关联，字幕包含说话人和时序信息。

## 流程

- Gather 配置仅扫描项目受控路径，排除测试临时文本与第三方不可修改内容。
- 源语言变更后重新 Gather、导出、翻译、导入并编译本地化资源。
- 伪本地化用于检测截断、遗漏、硬编码和双向布局风险。

## 测试

- 至少验证 `zh-Hans` 与 `en` 的菜单、HUD、教程、字幕、存档名称和错误提示。
- 运行时切换语言后，已打开界面必须刷新或明确要求重启。
