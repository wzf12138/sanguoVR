# C++ 编码标准

## 适用范围

适用于项目 `Source/` 与项目插件中的 Unreal Engine C++ 代码、Build.cs、Target.cs 及自动化测试代码。

## 强制规则

- 遵循 Unreal Engine 类型前缀：`U`、`A`、`F`、`E`、`I`、`T`；布尔成员使用 `b` 前缀。
- 头文件使用 `#pragma once`；对应 `.generated.h` 必须是最后一个 include。
- 优先前向声明；仅在需要完整类型时 include，禁止依赖传递包含。
- UObject 指针按生命周期选择 `TObjectPtr`、`TWeakObjectPtr`、`TSoftObjectPtr`；禁止无说明的裸 UObject 长期持有。
- 可由蓝图访问的 API 必须给出明确的 `Category`、访问级别和必要元数据。
- 成员变量默认 `private`；通过窄接口、只读访问器或受控命令暴露。
- 输入、存档、UI、动画、音频等跨系统调用通过接口、组件或子系统完成，禁止互相硬引用形成环。
- 日志使用项目 LogCategory；禁止以 `LogTemp` 作为提交代码的长期日志通道。
- 错误路径必须可诊断：开发期不变量用 `check`，可恢复异常用 `ensure` 与日志，外部数据一律校验。
- Tick 默认关闭；确需 Tick 时必须说明频率、停止条件和 Pico Neo 3 成本。

## 禁止事项

- 禁止提交编译警告、未使用变量、空 catch 式吞错逻辑或注释掉的大段旧代码。
- 禁止在构造函数中访问尚未初始化的世界、玩家或运行时子系统。
- 禁止把关卡 Actor 指针、Widget 指针或临时对象地址直接序列化到存档。
- 禁止在游戏线程每帧执行同步磁盘访问、资产扫描、大量动态分配或字符串拼接。
- 禁止使用魔法字符串定位输入动作、动画状态、存档字段或资源路径。

## 验证门槛

- Development Editor 与目标 Android 配置均能编译。
- Unreal Header Tool、静态分析与自动化测试无新增错误。
- 新增公共 API 有用途说明；高频路径有性能依据。
- 代码评审确认所有权、线程、网络/存档边界和失败处理清晰。
