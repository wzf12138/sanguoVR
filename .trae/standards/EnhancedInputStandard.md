# Enhanced Input 标准

## 资产结构

- 输入动作统一使用 `IA_`，映射上下文使用 `IMC_`。
- 至少划分 `IMC_VRGameplay`、`IMC_UI`、`IMC_Debug`；上下文按状态显式添加和移除。
- 动作表达意图，不绑定设备名称，例如 `IA_Grab`、`IA_Turn`，禁止 `IA_RightTrigger`。

## 强制规则

- 连续轴值使用 `Triggered`；一次性命令优先 `Started` 或 `Completed`，并记录选择原因。
- Trigger、Modifier 配置在资产层完成；代码层只处理业务语义。
- 左右手动作通过玩家 Mappable Key、输入槽或数据配置区分，不复制整套业务逻辑。
- UI 打开、失焦、暂停、死亡、过场和装载时必须切换或屏蔽对应 Mapping Context。
- 所有动作必须定义死区、归一化和控制器断连后的安全状态。
- 转向、移动、抓取、传送与菜单动作不得互相竞争同一按键而无优先级。
- 输入回调只发命令或更新短生命周期状态，不在回调中同步加载资产或执行存档。

## VR 特定要求

- 同时支持左右手控制器；主手设置只改变映射与 UI 提示，不破坏功能覆盖。
- 抓取使用按下、保持、释放三段语义；丢失跟踪或设备断连必须触发安全释放。
- Snap Turn 与 Smooth Turn 参数独立，默认提供舒适选项。
- UI 射线输入与世界交互必须有明确焦点仲裁。

## 测试

- 覆盖键位重映射、重复绑定、上下文叠加、暂停恢复、断连重连与左右手切换。
- 在 Pico Neo 3 真机验证动作延迟、摇杆死区和系统按键冲突。
