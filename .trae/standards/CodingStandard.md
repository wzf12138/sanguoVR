# C++ 与蓝图规范

- C++ 类型遵循 UE 命名前缀：`U`、`A`、`F`、`E`、`I`；布尔值使用 `b` 前缀。
- 公共 API 必须说明所有权、线程/生命周期假设、失败方式和日志分类。
- 运行时规则优先放 C++；调参、装配和表现层允许蓝图；禁止在关卡蓝图承载核心战斗规则。
- 模块依赖单向，禁止 UI、关卡或具体武器反向成为核心角色状态的事实源。
- 玩家与 AI 通过同一能力请求/命令接口驱动角色，不复制两套结算逻辑。
- 可配置数值进入 DataAsset、DataTable 或配置，不散落魔法数字。
- `check` 用于不可恢复程序错误，`ensure` 用于应报告但可继续的异常，玩家输入错误不得触发崩溃。
- 新系统必须提供日志分类、最小测试入口和重置路径。
