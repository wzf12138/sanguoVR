# UISystem

## 职责

管理 VR 世界空间界面、菜单栈、HUD、提示、焦点、输入模式、可访问性和界面生命周期。

## 边界

- Widget 展示 ViewModel/数据快照并发送用户意图，不直接修改存档、关卡或角色内部状态。
- UISystem 负责创建、缓存、显示和销毁 Widget；业务系统不得各自维护全局菜单栈。
- 文本由 LocalizationSystem 提供，输入提示由 InputSystem 提供，音效通过 AudioSystem 触发。

## 运行规则

- 菜单栈定义 Modal、Overlay、HUD 层级与返回行为。
- 每次打开界面必须设置初始焦点，关闭时恢复先前焦点与输入上下文。
- 世界空间 Widget 明确尺寸、交互距离、碰撞通道和销毁策略。
- 高频数值采用事件或节流刷新，禁止所有 Widget 每帧轮询世界。
- 加载、错误、空数据和禁用状态必须有明确表现。

## 验收

- 遵循 `VRUIUXStandard`；左右手、坐姿、语言切换和暂停恢复可用。
- 切关与重复开关菜单无重复实例、悬挂引用或输入泄漏。
- 真机 UI GPU/CPU 增量不超过性能预算。
