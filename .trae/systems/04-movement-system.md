# 移动系统工程实现指引

移动模式、战术瞬移、平滑移动、全身 IK 与安全恢复规则以 [`../knowledge/Design/MovementAndFullBodyIK.md`](../knowledge/Design/MovementAndFullBodyIK.md) 为权威产品详规。本文件只描述工程接口与边界。

## 工程职责

- 通过统一移动模式接口管理进入、退出、请求、取消与安全重置。
- 将落点、边界、占位和可站立性查询集中到移动服务。
- 协调玩家根组件、VR 原点、角色占位与 IK 输入。
- 向 UI、战斗、AI 和诊断系统发布查询与执行结果。

## 实现边界

UI 只展示移动查询结果，不自行判定合法性。各移动模式不得相互写入内部状态；后续模式通过接口扩展。越界、几何卡入和追踪恢复统一走安全点服务，不在移动层改变生命或胜负。

## 接口与验证

移动请求必须具备唯一标识、明确失败原因和可取消阶段。验证覆盖边界、坡度、占位、连续请求、模式切换、追踪恢复、攻击门控与根组件/IK 一致性；体验规则与参数从权威详规读取。
