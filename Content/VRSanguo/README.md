# Content/VRSanguo 目录说明

本目录是 VRSanguoYanWuchang 项目所有自有资源的唯一根目录。

## 子目录规划

- Core/      通用系统资产与共享逻辑
- VR/        VR 相关表现资产（手部、控制器表现）
- Combat/    战斗相关资产
- Weapons/   武器模型与配置
- Characters/ 角色资产
- AI/        AI 行为与配置
- Arena/     竞技场环境资产
- UI/        UI 资产
- Audio/     音频资产
- FX/        特效资产
- Data/      Data Asset 与配置数据
- Maps/      地图文件
- Developer/ 个人实验区
- ThirdParty/ 第三方资源（保持原包结构）

详细规范见 [`../../.trae/knowledge/DirectoryConvention.md`](../../.trae/knowledge/DirectoryConvention.md) 与 [`../../.trae/knowledge/AssetConvention.md`](../../.trae/knowledge/AssetConvention.md)。
